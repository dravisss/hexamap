# Roast checklist

Ask bluntly:

- Does the hexagonal form carry meaning, or could circles replace it without loss?
- Does any cluster look like a generic translucent blob?
- Are titles attached to the correct territory?
- Is there an accidental visual centre that has no semantic reason?
- Do arrows curve inward merely because the formula chose the wrong sign?
- Are relation labels colliding with cluster titles?
- Does fit-to-view make the content unreadably small?
- Does an empty drawer or toolbar consume more space than the map?
- Do modes create conceptual complexity without changing useful action?
- Can a new user infer grouping, decomposition, recombination, and connection from the interaction?
- Can an exported map be reconstructed exactly from JSON?
