# Código de Conduta

Esperamos uma comunidade acolhedora, técnica e respeitosa. Participe de boa-fé,
critique ideias e código — nunca pessoas — e aceite correções baseadas em
evidência. Não são tolerados assédio, discriminação, ameaças, exposição de
dados privados ou comportamento deliberadamente intimidatório.

Relate incidentes ao mantenedor por um canal privado, sem publicar dados
pessoais. O mantenedor pode remover conteúdo, pedir uma pausa ou encerrar uma
interação para proteger participantes.
